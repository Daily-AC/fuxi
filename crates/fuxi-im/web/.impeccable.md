# fuxi-im · v2 PWA Design Context

## Design Context

### Users

- **唯一用户**：以琳（fuxi 主理人）。单用户，无多租户。
- **场景**：白天 ERP 上班，从手机派活给 home fuxi；通勤/碎片看进度；插话回玄女。
- **核心 job**：跟玄女对话主导 — task / 节点是次要 surface。
- **设备**：iPhone 主力（PWA 添加到主屏），偶尔 Android。
- **认知负担**：用户对 fuxi 内部架构充分了解，UI 不必解释术语。

### Brand Personality

- **三词**：克制、技术感、自家味儿（不像别的 IM）。
- **声音**：直白，不寒暄不卖萌。错误说人话不掉书袋。
- **情绪目标**：信任 + 控制感 — "这是我自己的工具，安静干活"，不是 "AI 助手取悦我"。

### Aesthetic Direction（v2 重定调）

**减法是核心**：v1 失败在"功能堆砌 + 输入框在顶 + 玄女空荡 + emoji 残留"。v2 是大道至简的 IM：主屏 = 对话，副视图 sheet 召唤。

- **暗底 first**：`#0a0a0a`，不是纯黑。
- **正文 sans-serif**：PingFang SC / 系统字栈，15px 正文、16px 标题、18px 大标题、13px 次要、11px meta。等宽**仅限** code / 工具输出 / agent id。
- **平面卡片**：圆角（card 12 / bubble 14 / pill 22）但**纯平**——没有 shadow、gradient、glassmorphism、伪 3D。靠间距 + 1px `#262626` 细边切分。
- **触控热区 ≥ 44px**。
- **流式动效**：fuxi cyan pulse dot（不是字符 cursor）。除此之外 transition ≤ 200ms 无弹跳，`prefers-reduced-motion` 全关。
- **不用 emoji**。任何"图标需求"用 6px css 圆点 / 1 行小字代替。
- **不用 Unicode block 装饰**（▎┌─└→……是 TUI 语言，PWA 禁）。
- **anti-references**：WeChat / Slack / iMessage / Telegram 的视觉签名一律避开。Material shadow、glassmorphism、紫蓝 AI 助手霓虹光全禁。

### Design Principles

1. **对话是主语**：主屏永远是 chat。任务 / 节点是 sheet 召唤。
2. **小屏密度优于装饰**：靠 typography 层级 + 间距 + 1px 细边切结构，不靠 effect。
3. **fuxi cyan pulse dot 是唯一花活**：除流式 pulse 外无非必要动画。
4. **等宽出现 = 这块内容真的需要等宽**：agent id、code、tool 输出、diff——其余一律中文 sans。
5. **触控优先**：每个交互元素 44px 起；hover 状态可以有但不依赖。
6. **不为视觉牺牲信息**：状态色用低饱和、色盲下可区分，必要时配文字标签。
7. **role tint 用于身份**：玄女紫 / 鲁班金 / 蒲松绿。User bubble 用 `userBubble` 蓝。
