# fuxi-im · PWA Design Context

## Design Context

### Users

- **唯一用户**：fuxi 项目主理人（以琳）。单用户系统，无多租户。
- **使用场景**：白天在 ERP 公司上班，需要从手机派活给家里的 fuxi 集群（让 home cc 干 ERP 维护）；通勤/碎片时间看进度；偶尔插话回玄女。
- **核心 job**：派活 → 离开 → 半路看进度 → 必要时插话。任务生命周期是主线，不是聊天流。
- **设备**：iPhone 主力（PWA 添加到主屏），偶尔 Android。深夜/早高峰使用。
- **认知负担**：用户对 fuxi 内部架构（玄女 / 门客 / EventKind / task tree）已充分了解 —— UI 不需要解释术语，但需要在小屏上清晰承载这些概念。

### Brand Personality

- **三词**：克制、技术感、自家味儿（不像别人家的 IM）。
- **声音**：直白，不寒暄，不卖萌。错误信息说人话，不掉书袋。
- **情绪目标**：信任 + 控制感。用户应该感觉"这是我自己的工具，安静地干活"，而不是"app 在拼命取悦我"。
- **明确不要**：兴奋感、社交感、营销感、"AI 助手"那一套阳光开朗人设。

### Aesthetic Direction

- **暗底 first**：`#0a0a0a` 系底色，不是纯黑（避免 OLED 刺眼对比）。继承 fuxi TUI 的 dark theme 气质但**不抄 TUI 视觉**。
- **正文中文 sans-serif**：PingFang SC / 系统字栈，16–17px。等宽**只用于** code block / tool 输出 / agent id（如 `cc-7b3f`、`xuannv` ID 显示）。
- **平面卡片**：圆角（10–14px）但**纯平**——没有 shadow、gradient、glassmorphism、伪 3D。靠间距和细边框（1px `#1a1a1a` 系）切分。
- **触控热区 ≥ 44px**：所有可点元素严格遵守。
- **字符级流式**：玄女/门客回复逐字渲染，参考 cc TUI 体验——这是 fuxi 自己的"signature motion"，唯一允许的"花活"。
- **不用 emoji**（默认）：fuxi 哲学是文字 / Unicode block / 文字优先。如果某个状态非要图形，用 1 个 css-drawn 圆点或线条，不开 emoji 口子。
- **anti-references**：
  - WeChat / Slack / iMessage 的气泡 + 头像 + 时间分组视觉
  - shadow-heavy "Material" 卡片
  - glassmorphism / 毛玻璃
  - 渐变 accent 按钮
  - "AI 助手"那种紫蓝霓虹光
  - TUI 等宽 + ASCII art 直搬手机
- **accent 色**：保留 1 个低饱和强调色（暂定青绿，跟 TUI accent 同源），用在：active 状态、focus ring、未读标识、流式光标。**不**用作大面积填色。

### Design Principles

1. **任务是主语，对话是谓语**：信息架构始终围绕 task 卡片展开，chat 永远嵌在 task 里。主屏永远不是"消息列表"。
2. **小屏密度优于装饰**：单屏能看到 5–7 张任务卡比看到 3 张带阴影的卡更有用。靠排版 + 间距承担视觉层次，不靠 effect。
3. **字符级流式是唯一的"花活"**：除流式渲染外，任何 transition 都 ≤ 200ms 且无弹跳。`prefers-reduced-motion` 直接关掉所有非必要动画。
4. **等宽出现 = 这块内容真的需要等宽**：agent id、code、tool 输出、diff——其余一律中文 sans。
5. **触控优先，鼠标兼容**：每个交互元素 44px 起；hover 状态可以有但不依赖。
6. **不为视觉牺牲信息**：状态色（idle/busy/done/failed）用低饱和、可在色盲模式下区分的色相，必要时配 1 个文字标签。

### Concrete Tokens (initial)

| token | value | 用途 |
|---|---|---|
| `--bg-0` | `#0a0a0a` | app 底色 |
| `--bg-1` | `#121212` | 卡片底 |
| `--bg-2` | `#1a1a1a` | hover/active 卡片底、分隔 |
| `--fg-0` | `#e8e8e8` | 正文 |
| `--fg-1` | `#a0a0a0` | 次要文字 |
| `--fg-2` | `#6a6a6a` | 时间戳/meta |
| `--accent` | `#5fd3a8` | active / focus / 流式光标 |
| `--accent-dim` | `#3a8a6c` | accent 低亮态 |
| `--state-busy` | `#d8a85f` | 任务运行中 |
| `--state-done` | `#5fd3a8` | 完成 |
| `--state-fail` | `#d86a5f` | 失败 |
| `--border` | `#222222` | 1px 细边 |
| `--radius` | `12px` | 卡片圆角 |
| `--radius-sm` | `8px` | 按钮/输入 |
| `--touch` | `44px` | 最小热区 |
| `--font-sans` | `'PingFang SC', -apple-system, BlinkMacSystemFont, 'Helvetica Neue', system-ui, sans-serif` | 正文 |
| `--font-mono` | `'SF Mono', Menlo, Consolas, 'Liberation Mono', monospace` | code/agent id |
| `--text-body` | `16px` | 正文 |
| `--text-body-lg` | `17px` | iOS 偏好 |
| `--text-meta` | `13px` | 时间戳/次要 |
| `--text-mono` | `13.5px` | 等宽内容 |
