## 1 · B1 · 抄送通路：用户直接对门客说话，玄女必须收到

**为什么要测**：公理 #2（玄女永远有知情权）。上一轮测试这个通路是断的——玄女说"没收到抄送"。

**步骤**：

1. `fuxi` 启动 TUI。
2. 对玄女说：`起一个鲁班（luban）门客`。
3. 等玄女回复"门客已就绪"，左栏"空闲门客"或"任务"里能看到 `luban`。
4. `Tab` 循环或**鼠标左键**点击左栏 luban 那一行，切到和 luban 的对话。输入框标题应变成 `你 → luban`。
5. 对 luban 发：`你好门客，测试抄送`。
6. `Esc` 或点左栏玄女行切回玄女。
7. 问玄女：`我刚才对门客说了啥？`

**预期**：

- 玄女能**原文复述**或至少识别出"用户对门客 luban 说了『你好门客，测试抄送』"。
- 对话区她的回复前会有一条 `[CC] 用户直接对门客 ...（role=luban）说：「你好门客，测试抄送」` 注入（在她的 cc 侧，TUI 可能只看到她说的话）。
- 事件面板应有 `📣 抄送 · ...` 这条事件（F2 开事件面板看）。

**结果**：
ok

## 2 · B2 · 门客派活后从"空闲"移到"任务"

**为什么要测**：上一轮你复现"玄女派活给鲁班后鲁班还在空闲队列"。根因是 `Fuxi::dispatch` 不发 `TaskDispatched` 事件，这轮补了。

**步骤**：

1. 继续上一个 REPL 会话（或重启都行）。
2. 对玄女说：`起一个鲁班，派个活给他：慢慢数到 50，每数一个报一下`。
3. 观察**左栏**：

**预期**：

- 短暂的"空闲门客 luban"出现后，luban 应从"空闲门客"**消失**，出现在"任务"区域下（玄女之下）挂一个子项，大概显示 `▶ 🔵 luban  [数 50]` 之类。
- 事件面板能看到 `◇ 新任务 · ...` + `→ 接单 · ...` 两条。
- 任务跑完（或 cancel 后）几秒 luban 回到"空闲门客"。

**反例**：如果 luban 一直在空闲区 → B2 没修好，失败。

**结果**：
ok

## 3 · B3 · 对话区满了还能看到最新

**为什么要测**：上一轮你反馈"会话区满了之后吞最新的输出，没办法上滑看最新"。根因是 `Paragraph.scroll` 按屏幕行算，但之前用逻辑行算 scroll，CJK/wrap 后底部被切。

**步骤**：

1. 玄女对话里故意让她输出一大段长文字（粘贴中文段落或让她"详细解释 10 条规则"）。
2. 不动鼠标不按键，等她输出完。
3. 看对话区底部。

**预期**：

- 对话区**最后一行**应贴着输入框上边——最新的那行能看见，不被遮。
- 按 `PgUp` 能往上翻看之前的内容，`End` 或 PgDn 能回到底部。
- 鼠标滚轮上下滚也生效（mouse_enabled=on 时，默认）。

**反例**：如果最新几行不可见、内容被"吃掉"看不到 → B3 没修好。

**结果**：
ok

## 5 · U2 · Resume 启动横幅

**为什么要测**：策府存的 session_id 让玄女 cc 能续写上下文，但 TUI 对话区是空的——用户不知道"续上"没有。这轮加了启动横幅。

**步骤**：

1. 先跑**一次**上面任何场景（比如 B1/B2），跟玄女说几句话，**Ctrl+C 退出** fuxi。
2. 再跑一次 `fuxi`。
3. 看对话区最顶一行。

**预期**：

- 对话区顶部有一条斜体黄色 system 消息：`· 已续写玄女上次 session（xxxxxxxx…）—上下文保留在 cc 端，TUI 对话历史不回放。直接开口接着聊。`
- 你直接问"刚才我问了你啥"，玄女应该能答上——说明 cc 真的续上了（B1 抄送那轮的话题或 B2 派活）。

**反例**：
- 没有横幅 → U2 没修好。
- 有横幅但玄女说"不记得/这是第一次对话" → cc 的 `--resume` 没通（属于 Bug 3 续写链路问题，比 U2 深）。

**结果**：

## 6 · U3 · F3 切鼠标捕获以复制内容

**为什么要测**：ratatui `EnableMouseCapture` 吞掉终端原生 select/copy，你想复制会话内容时抓不到。F3 toggle 开关解决。

**步骤**：

1. 默认进入 TUI，鼠标滚轮应能滚对话区（mouse_enabled=on）。
2. 按一下 **F3**。

**预期**：

- 对话区或玄女 bucket 里 push 一条 system 提示：`· 鼠标捕获：关（终端原生选中复制可用，F3 再切回）`。
- 用鼠标拖选对话区文字，终端应**像普通 shell 那样**高亮选中，`Cmd+C` 能复制到剪贴板。
- 再按 F3，提示切回 `· 鼠标捕获：开（滚轮/点击可用）`，此时再试鼠标选中应又选不了——滚轮恢复。

**结果**：
ok
