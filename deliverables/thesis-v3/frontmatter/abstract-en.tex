  {\sffamily\zihao{-2}\bfseries ABSTRACT}
\end{center}

\vspace{1em}

With the rapid progress of large language models and tool-use techniques, AI agents are evolving from single-turn assistants into autonomous execution units that understand goals, decompose tasks, invoke external tools and continuously report progress. When multiple agents collaborate, a platform must simultaneously address task orchestration, inter-process communication, state consistency, execution isolation, real-time observability and fault recovery. Existing multi-agent frameworks are primarily built on Python platforms with role-driven dialogue flows, leaving room for improvement in local-first, high-performance and auditable distributed communication infrastructure. In particular, although Agent2Agent (A2A) already has an official Rust SDK (\texttt{a2a-rs}, maintained by a2aproject) alongside several third-party crates, none of them deeply integrates with a local-first orchestration layer, an event bus and human-in-the-loop semantics, which constrains the deployment of audit-friendly, observable Rust-based agent platforms.

This thesis designs and implements Fuxi, a Rust-based platform that addresses these gaps. Fuxi adopts a hierarchical Xuannv-Menke collaboration pattern that separates the user-facing orchestrator agent from worker agents. Fuxi provides a from-scratch Rust implementation of an A2A v1.0 compatible wire protocol, JSON-RPC server and client, and core data structures such as AgentCard, Task, Message and Artifact, co-evolving with the platform's event bus and orchestrator, and extending an InputRequired state for human-in-the-loop scenarios. A real-time event bus is built on top of Tokio broadcast and SQLite WAL so that live subscription and historical replay coexist on the same abstraction. Observability is exposed through Firehose, WebSocket, SSE and IM APIs, and execution is isolated through Git worktrees and a three-layer sandbox. The thesis further formalizes end-to-end latency decomposition, broadcast event latency lower bounds and a Worker selection function, providing a quantifiable basis for performance analysis.

Experimental evaluation on an Apple Silicon platform measures throughput, latency, parameter sensitivity and event bus stress along multiple dimensions. Under a synthetic benchmark in which each task is modeled as a 10 ms sleep (isolating the orchestration layer from LLM inference), Fuxi sustains 665.00 tasks per second with 8 workers, and scales to 1288.24 tasks per second with 16 workers, with the 1-to-16-worker range exhibiting 80.5\%--83.1\% scaling efficiency and the dispatcher remaining unsaturated within this range. The p50 task dispatch latency is 32.93 ms (covering HTTP, SQLite and deserialization), and the p99 in-process event-bus fan-out latency is 0.26 ms. With 64 concurrent subscribers, the event bus sustains 10\,000 events per second with zero drops. These synthetic numbers measure the throughput ceiling of the orchestration and communication layers after factoring out LLM inference; end-to-end throughput under real LLM Agent tasks is dominated by per-inference latency (typically 1--30 s). Collectively, the results validate the design hypothesis that event-driven semantics combined with append-only logging delivers a communication substrate that simultaneously achieves throughput, real-time responsiveness and traceability for local-first AI agent collaboration, providing a reusable foundation for future multi-agent system engineering.
